Page Annotations: Order Status Page (Wireframe 07 of 17)

Three states shown in one file: the lookup form, the order found with Processing status, and the order found with Shipped status. Plain English throughout.

State 1: Lookup Form

What a customer sees when they arrive at this page cold, either from a bookmark, from the footer link, or from the confirmation page. Two fields: order number and email address. Both must match an order record in the database for the lookup to succeed. If they don't match, a red error message appears below the form. Jean's email address is shown as a fallback for customers who can't find their order number.

Business rule: The order number and email address together act as the authentication for guest checkout orders. No password is needed. Both fields must match exactly.
Deep-Link Pre-Fill

When a customer clicks "Check Order Status" from the Order Confirmation page, the URL carries the order number as a parameter (e.g., /order-status?order=DD-2027-0042). The order number field is pre-filled automatically. The customer only needs to enter their email address and click Look Up. This was flagged as a note in Wireframe 06.

Four-Step Status Tracker

A visual progress indicator showing four stages: Received, Processing, Shipped, Delivered. Completed steps are shown in green with a checkmark. The current active step is highlighted in blue. Future steps are grey. The date each stage was reached appears below each step when it is completed. This tracker updates automatically as Jean advances the order status in her admin panel.

Decision needed: Should a "Delivered" step be included even though the system has no way to automatically confirm delivery? The Delivered status would only show if Jean manually marks it, which she is unlikely to do routinely. An alternative is to end the tracker at "Shipped" and let the USPS tracking link handle the rest. Jean should decide.
Tracking Number Box (Shipped state only)

A green-tinted panel showing the USPS tracking number Jean entered in the admin Order Detail view, the date Jean marked the order shipped, and a "Track on USPS" button that opens the USPS tracking page in a new tab. This panel only appears once Jean has marked the order as Shipped and entered a tracking number. It is invisible in the Received and Processing states.

Business rule: Jean enters the tracking number manually in the admin Order Detail page when she ships. The system does not auto-generate or auto-update tracking. Jean emails customers personally when she ships; this page is for customers who want to check without waiting for Jean's email. Decision needed: Should the "Track on USPS" button open USPS specifically, or should it be a generic "Track Package" link? Jean uses USPS for shipping, but this could change. If Jean ever switches to UPS or FedEx, a hard-coded USPS link would be wrong. A simple approach: just display the tracking number as plain text and let the customer copy-paste it into any carrier's site. Simpler and more resilient.
Order Items and Totals

The full list of plants ordered with quantities and prices, plus the subtotal, shipping, and total. Identical to what was shown on the confirmation page and in the confirmation email. Gives the customer a complete record without needing to dig up the email.

Contact Jean Box (sidebar)

A warm-toned panel with Jean's email address and a reminder to include the order number. The order number is pre-filled in the suggested text so customers can copy it directly. Reduces friction for customers who need to reach out.

"Look Up a Different Order" Link

Appears in the top-right of the order header band once an order is loaded. Returns the customer to the lookup form so they can search for a different order number, useful for customers who placed multiple orders or who are helping a family member.

No Login Required

This page works entirely without an account. Order number plus email is the only authentication. Customers can bookmark the page at any URL and return anytime. If they arrive without a pre-filled order number they just enter it in the lookup form.
