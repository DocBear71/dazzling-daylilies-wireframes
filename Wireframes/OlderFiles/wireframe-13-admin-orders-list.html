Dazzling Daylilies Admin • Logged in as Jean View Public Site • Settings

Page Annotations: Admin Orders List (Wireframe 13 of 17)

This is Jean's primary order management view. The wireframe shows the "New" tab active, which is the state Jean will see most often when she logs in during the shipping season. Plain English throughout.

Season Total (top right of heading row)

A running total of orders and revenue for the current season, always visible at the top of the page. Gives Jean an at-a-glance sense of how the season is going without needing to open the dashboard. The definition of "season" is the same question raised in Wireframe 09: Jean should confirm whether this resets on a calendar year or a shipping-season basis.

Status Filter Tabs

Five tabs: All, New, Processing, Shipped, Delivered. The count badges update in real time as orders change status. New orders are highlighted with a red badge to make them impossible to miss. The wireframe opens on the New tab, which is the most likely starting point for Jean every morning during the season. Clicking any tab instantly filters the table to that status. The "All" tab shows every order regardless of status.

Business rule: "New" is the same as "Received" in the database (fulfillment_status = 'received'). The admin uses "New" as the label because it is more intuitive for Jean as an action signal: these orders need her attention. The customer-facing Order Status page uses "Received" as the label.
Search Box

Searches by customer name or order number. Jean can type "Margaret" to find Margaret Thornton's order, or type "DD-2027-0038" to go directly to a specific order number. Search works across all statuses regardless of which tab is active.

Decision needed: Should search also match on customer email address? Jean may want to look up "linda.s.garden" and find Linda Sorensen's order. Email search adds minimal complexity. Worth including unless Jean prefers name and order number only.
Date Filter

Filters by time window: All time, Last 7 days, Last 30 days, or This season. Useful at the end of the season when Jean wants to review what shipped during a specific window, or if she wants to find an older order without scrolling through everything.

New Order Rows (amber highlight, red dot)

Orders in New status are highlighted in amber with a red dot next to the order number. This matches the dashboard treatment so Jean sees a consistent visual signal: amber with red dot always means "this needs your attention." The amber highlight disappears as soon as Jean marks the order as Processing from the Order Detail page.

Customer Column: Full Name and Email

Shows the customer's full name and email address in the same cell, stacked. Jean can see at a glance who ordered and copy the email address if she needs to reach them. Unlike the dashboard (which showed abbreviated names), this table shows full names because Jean is working these orders one by one and needs complete information.

Plants Column: Mini Thumbnails

Shows the first three plant photo thumbnails as tiny squares, with an overflow label ("+ 2 more") if the order has more than three plants. This gives Jean a quick visual reminder of what is in each order without opening it. The thumbnails are the same primary photos shown on the public catalog.

Decision needed: Mini thumbnails in the list view add visual richness but require the thumbnail photos to load for every visible row. On a slow connection this could make the orders list feel sluggish. If performance is a concern, thumbnails can be replaced with a simple "3 plants" text label. Jean should indicate whether the visual benefit is worth it to her.
Restricted State Flag (amber pill on DD-2027-0036)

When an order was placed with a flagged-state address (TX, CA, AZ, FL) and the customer clicked "I understand" to proceed, a small "TX notice shown" pill appears in the status column. This flags the order for Jean so she knows to review it before shipping. Jean should reach out to confirm the order can be fulfilled before packing it.

Business rule: The restricted_state_notice_shown flag in the orders table drives this indicator. Jean sees it in the list view and in the Order Detail view. It does not block the order; it is a reminder for Jean to review before shipping.
Open Button

The primary action for each row. Takes Jean to the Admin Order Detail page for that order. New orders show the Open button in blue to draw the eye. Older orders show it in grey. Clicking anywhere on the row also opens the order detail.

Export as CSV Link

Exports the currently visible filtered view as a CSV file Jean can open in Excel or Google Sheets. Useful for Jean's own record-keeping at end of season, or if she wants to reconcile with her Square transaction history. The export includes all columns: order number, date, customer name, email, items, total, status.

Decision needed: Should the CSV export be scoped to the current filter (e.g., only New orders if the New tab is active), or always export all orders? Scoped export is more useful for targeted tasks. Full export is better for end-of-season bookkeeping. Both options could be offered. Jean should indicate her preference.
